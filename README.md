# DIY Sauna Creator

Интерактивный 3D-конфигуратор инфракрасной сауны в браузере. Все размеры — в **дюймах (in)**.

## Возможности

- Задание размеров комнаты (ширина × глубина × высота)
- Выбор стены и положения двери
- Скамейки: 1 или 2 яруса, на стене или на полу; перетаскивание мышью
- Нагреватели: карбоновые или керамические панели из пресетов; перетаскивание и высота от пола
- Вид среза: без крыши и передней стены
- Экспорт схемы в **PNG** и **PDF** со спецификацией

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:5173

## Сборка

```bash
npm run build
npm run preview
```

## Управление

| Действие | Как |
|----------|-----|
| Вращение камеры | ЛКМ + перетаскивание |
| Масштаб | Колесо мыши |
| Выбор объекта | Клик по скамейке или нагревателю |
| Перемещение | Перетаскивание выбранного объекта в 3D |
| Удаление | Delete или кнопка в панели |

## Стек

- React + Vite + TypeScript
- Three.js, @react-three/fiber, @react-three/drei
- Zustand, Tailwind CSS, jsPDF
